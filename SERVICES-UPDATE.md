# Services Page Update

This build includes a complete dedicated Services page at `/services`.

## Implemented

- Photography, video production, social media content and graphic design service sections
- Deliverables and best-use guidance for every service
- Four-step project process
- FAQ section
- Contact calls to action with project-type preselection
- Service structured data and page metadata
- Services added to desktop navigation, mobile navigation, footer and sitemap
- Homepage service links now point to the relevant Services-page section
- The expanded commercial Portfolio page and supplied social links are included
- Google Analytics integration is retained

## Publish

```bash
npm install
npm run build
git add .
git commit -m "Add dedicated creative services page"
git push
```
